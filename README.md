# MRKT.ia · Desk

Desk de news pour traders **Nasdaq (NQ) et Or (GC)** : fil de news notées de 1 à 5 avec leur impact sur le NQ et l'or, calendrier éco, zone rouge avant les gros chiffres US, earnings des gros poids du Nasdaq, récaps de 8h / 14h / dimanche, notifs sur téléphone. Gratuit, sans compte.

## ⬇️ Télécharger

**👉 [Télécharger MRKT.ia (Windows)](https://github.com/saudade-lab/bloomberk-terminal-/releases/latest/download/MRKT-ia.zip)**

## Installer (2 min)

1. Dézippe le dossier `MRKT-ia` où tu veux (par exemple sur le Bureau).
2. Double-clique sur **MrktIaWatcher.exe**. Si Windows affiche « Windows a protégé votre ordinateur », clique sur *Informations complémentaires* puis *Exécuter quand même*.
3. Ouvre **http://localhost:5057** dans ton navigateur (ou double-clique sur *Ouvrir-Dashboard*).

Le fichier **LISEZMOI.txt** dans le dossier explique le reste : notifs sur téléphone (appli ntfy), IA optionnelle, NinjaTrader.
