# MRKT.ia · Desk

Desk de news pour traders **Nasdaq (NQ) et Or (GC)** : fil de news notées de 1 à 5 avec leur impact sur le NQ et l'or, calendrier éco, zone rouge avant les gros chiffres US, earnings des gros poids du Nasdaq, récaps de 8h / 14h / dimanche, notifs sur téléphone. Gratuit, sans compte.

- **🍎 Mac puce Apple (M1, M2, M3, M4…) : [Télécharger pour Mac Apple](https://github.com/saudade-lab/bloomberk-terminal-/releases/latest/download/MRKT-mac-arm64.zip)**

Ton Mac a quelle puce ? Menu  › *À propos de ce Mac*.

## Installer sur Windows (2 min)

1. Dézippe le dossier `MRKT-ia` où tu veux (par exemple sur le Bureau).
2. Double-clique sur **MrktIaWatcher.exe**. Si Windows affiche « Windows a protégé votre ordinateur », clique sur *Informations complémentaires* puis *Exécuter quand même*.
3. Ouvre **http://localhost:5057** dans ton navigateur (ou double-clique sur *Ouvrir-Dashboard*).

Le fichier **LISEZMOI.txt** dans le dossier explique le reste : notifs sur téléphone (appli ntfy), IA optionnelle, NinjaTrader.

## Installer sur Mac (3 min)

1. Double-clique sur le zip : un dossier `MRKT-ia` apparaît, range-le où tu veux (par exemple dans Documents).
2. **Première fois seulement** : ouvre l'app **Terminal**, tape `bash ` (avec un espace), glisse le fichier `lancer.sh` du dossier dans la fenêtre, puis Entrée. Ça débloque l'app (macOS bloque les apps qui ne viennent pas de l'App Store) et ça la lance.
3. Les fois suivantes : double-clique sur **Lancer MRKT.command** dans le dossier.
4. Le dashboard s'ouvre sur **http://localhost:5057**.

Sur Mac, les prix viennent de Yahoo Finance (différés d'environ 10 min), NinjaTrader n'existant pas sur Mac.
